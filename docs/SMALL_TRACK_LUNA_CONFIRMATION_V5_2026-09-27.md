# Frozen matched training-set evaluation

The user requested a fresh confirmed measurement after training on all available official papers, with no holdouts. The evaluation is the original canonical2023 paper:37 items,60 points and19 original PNG images. All36 nonessay evaluation tasks are present in the225-row training dataset; the evaluation essay is absent because its scoring rubric is not an exemplar. Five other official worked essays supervise the essay adapter. This is explicitly a training-set measurement, not generalization evidence.

The frozen policy is `scripts/small_track/luna_confirmation_policy_v5.json`, SHA256 `e4d579e874a7eec9ca1b4191ad8a540b14caea70c1c433500aa7dde849a9c870`. Both arms must use the same original input, derived OCR, router, runtime, prompt, seed, temperature and token caps. The only changed factor is explicit zero adapter scales versus the selected newly trained adapter. Require all37 saved answers, preserve blanks, reject transport errors, and verify all five loaded adapter IDs, paths, initial zero scales and weight hashes. Reconstruct every request hash and verify original question/image provenance before release to judging.

Use only the user's own authenticated Codex `gpt-6-luna`. No Forgehand judge, Astra grading, historical grade reuse or assistant reassignment. Candidate answers and CKE evidence are blinded to model arm and prior verdicts. Sixteen identical-image groups, one13-item short-text batch and three independent essay calls per arm give40 initial calls, with at most four concurrent workers and180 seconds per call. Every response and call state is retained. A completed or interrupted call is never automatically retried.

The first essay mark is primary. Two identical independent repeats detect instability; they are never averaged, voted or selected by score. Point conditions, components, earned totals, uncertainty reasons and truthful image-inspection metadata must agree. Image inspection may be unnecessary for a specific decision such as an empty answer; require an explicit explanation rather than a fabricated inspection claim.

Any schema/transport failure, unresolved evidence, arithmetic or logical contradiction, or essay repeat disagreement triggers exactly one additional blind rubric clarification for that item in that arm. The clarification receives only the same frozen answer, official rubric and original images. It sees no previous mark or rationale, arm label or target score. Its justified, internally consistent, resolved verdict is final whether lower, equal or higher. Otherwise the item stays unresolved. There is no retry until success, no highest-score selection and no assistant adjudication.

A confirmed exact full-paper score requires all37 decisions to resolve. An exact paired improvement requires both arms to resolve under this same protocol. For remaining uncertainty, show settled points plus0..official maximum for unresolved items, with exact score null. Even a threshold-proving bound is not an exact confirmed score. Confirmation means protocol completeness, not infallible model judgments. At least35% requires21/60; strictly above35% requires22/60.

Every report includes category maxima4/7/11/23/15 for closed without images, closed with images, open without images, open with images and essay. Include matched base/trained delta only under v5. Ania's Bielik1.5 reference15/55 (27.27%; closed5/11, open9/29, essay1/15) uses different adapted inputs and lacks five-way detail, so it is not a controlled comparison.

The executable runner `scripts/small_track/run_luna_confirmation_v5.py` defaults to a dry run. `--execute` runs the initial stage, freezes the mechanically selected clarification plan, runs that stage and writes JSON/Markdown reports. `--report-only` aggregates saved responses without calls. Policy, packets, original images, inference files and current-run verdict hashes are checked on resume. Costs use the local Codex plan; monetary usage is unknown.
